# 📚 Goodreads Web Scraping Project

## 📖 Project Overview
This project demonstrates web scraping using Python. The objective is to collect book information from Goodreads and organize it into a structured dataset for analysis.

## 🎯 Objectives
- Scrape book details from Goodreads.
- Extract useful information such as:
  - Book Title
  - Author
  - Rating
  - Number of Ratings
  - Genre
- Store the collected data in CSV format.
- Perform basic data cleaning and analysis.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Requests
- BeautifulSoup (bs4)
- Pandas
- NumPy
